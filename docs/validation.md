# Проверка базы знаний

> Файл собирается из `content/quiz.json` и `scripts/personas.ts` командой `npm run docs`. Правки вносятся туда, а не сюда.
Та же проверка, но с ошибкой при нарушениях, — `npm run check`.

## Требования задания

| Требование | Нужно | В системе |
|---|:-:|:-:|
| Вопросов | ≥ 20 | 23 (задаётся не меньше 20) |
| Параметров от пользователя | ≥ 10 | 23 |
| Объектов ранжирования | ≥ 20 | 24 |
| Свойств у объекта | ≥ 10 | 13 |
| Вариантов после каждого ответа | ≥ 5 | 5 лучших + весь рейтинг по кнопке |

## Баланс сфер

Максимум M у всех направлений одинаковый: Дети — 24, Инклюзия — 24, Старшие — 24, Экология — 24.
Ожидаемая сумма баллов при случайных ответах без правил тоже одинаковая: Дети — 10,03, Инклюзия — 10,03, Старшие — 10,03, Экология — 10,03.

## Случайные ответы

20 000 анкет: в вопросе с одним ответом вариант выбирается равновероятно, в вопросе с несколькими каждый вариант отмечается с вероятностью 1/2, правила применяются как в интерфейсе. Наименьшее число заданных вопросов — 20.

| Направление | Побед | Средний процент |
|---|:-:|:-:|
| Дети и подростки | 23,3 % | 38,6 % |
| Люди с инвалидностью | 27,6 % | 41,8 % |
| Старшее поколение | 27,3 % | 41,8 % |
| Экология | 21,8 % | 38,2 % |

Слабо выраженная склонность (меньше 50 %) — у 20,8 % анкет, почти равное второе место (разрыв меньше 10 п. п.) — у 53,8 %.

«Дети» и «Экология» побеждают немного реже, потому что правила П1–П4 выводят отказные ответы именно в их блоках: при случайных ответах человек, который написал, что с детьми ему неуютно, дальше уже не может «случайно» пообещать ходить к детям полгода.
