# Методика: как устроена экспертная система

## Задача

Прототип экспертной системы определяет волонтёрскую направленность личности. Он задаёт пользователю вопросы о предпочтениях, возможностях и склонностях. После каждого ответа он ранжирует 24 вида волонтёрской деятельности, а в конце называет направленность — одну из четырёх сфер — и объясняет выбор.

| Компонент | Где лежит |
|---|---|
| База знаний: атрибуты, объекты, вопросы-параметры с весами, правила | [`content/quiz.json`](../content/quiz.json), описание — [knowledge-base.md](knowledge-base.md) |
| Рабочая база данных: параметры текущего сеанса | браузер (localStorage), просмотр — экран «Рабочая БД» |
| Механизм логического вывода | [`src/engine/scoring.ts`](../src/engine/scoring.ts): `infer`, `buildProfile`, `rankObjects`, `evaluate` |
| Подсистема объяснений | там же: `explain` и вклад атрибутов в совпадение |
| Интерфейс пользователя и просмотр базы знаний | [`src/App.tsx`](../src/App.tsx), [`src/components/`](../src/components) |
| Проверка базы знаний | [`scripts/check-quiz.ts`](../scripts/check-quiz.ts), результаты — [validation.md](validation.md) |

## База знаний

**Атрибуты (13).** Четыре сферы: дети и подростки, люди с инвалидностью, старшее поколение, экология. Девять атрибутов стиля: физическая нагрузка, работа на улице, эмоциональная нагрузка, регулярность, специальная подготовка, организация и лидерство, обучение и объяснение, творчество и игры, работа один на один.

**Объекты ранжирования (24).** По шесть видов деятельности на направление — от наставника ребёнка из детского дома до автора экопроекта. Каждый описан выраженностью всех 13 атрибутов по шкале от 0 до 3. Например, «Вожатый в детском лагере»: дети 3, работа на улице 3, лидерство 3, творчество 3, физическая нагрузка 2, подготовка 2 и т. д.

**Параметры (23).** Каждый вопрос — параметр рабочей базы данных. Вопросы идут в пяти блоках: общий «Мотивы и стиль» (7 вопросов) и по 4 вопроса в блоке каждого направления. В 18 вопросах один ответ, из них 4 ситуационные задачи; в 5 — несколько ответов.

**Связи «параметр + атрибут».** Каждый вариант ответа даёт «преимущество» атрибутам:

| Вес | Что означает |
|:-:|---|
| 3 | Сильный прямой признак: выбрано занятие сферы, есть регулярный опыт, готовность к трудностям, лучшее решение ситуационной задачи |
| 2 | Заметный признак: эпизодический опыт, готовность при поддержке, хорошее, но не лучшее решение |
| 1 | Слабый признак: интерес без опыта, одно занятие из списка, общая черта с соседней сферой |
| 0 | Связи нет |
| −1, −2 | Только для атрибутов стиля: ответ говорит против атрибута («предпочитаю помогать в тепле и чистоте» — против работы на улице) |

Принципы расстановки:

1. **Монотонность.** Чем сильнее ответ выражает интерес, опыт или готовность, тем больше вес. Отказ даёт своей сфере 0 и не добавляет баллов другим.
2. **Перекрёстные веса — только при общей черте.** Спокойная беседа и помощь конкретному человеку объединяют работу с пожилыми и с людьми с инвалидностью. Ведение группы и генерация идей объединяют работу с детьми и экопроекты. В вопросах с несколькими ответами стыки замкнуты в цикл: занятия с детьми с особенностями развития, общение с теми, кто с возрастом стал хуже слышать, озеленение двора с пожилыми соседями, экоуроки для школьников.
3. **Баланс сфер.** Максимум по сфере у всех направлений одинаковый — 24 балла, вопросы о стиле на сферы не влияют.
4. **Ситуационные задачи** проверяют понимание специфики направления: лучшее решение — 3, приемлемое — 2, ошибки — 0.

**Правила «параметр + параметр» (4).** Если условие выполнено, система сама присваивает значение другому параметру, и этот вопрос не задаётся:

| Правило | Если | То |
|:-:|---|---|
| П1 | «Опыт общения с детьми» = «Нет, с детьми мне обычно неуютно» | «Готовность к постоянству с детьми» = «Мне ближе разовые акции» |
| П2 | «Время на волонтёрство» = «Только иногда — на разовых акциях» | «Готовность к постоянству с детьми» = «Мне ближе разовые акции» |
| П3 | «Экология в повседневной жизни» = «Никак, эта тема меня мало волнует» | «Интересные экопроекты» = «Ни в каких» |
| П4 | «Отношение к физической нагрузке» = «Мне противопоказана физическая нагрузка» | «Отношение к грязной работе» = «Предпочитаю помогать в тепле и чистоте» |

Даже если сработают все правила, пользователю задаётся 20 вопросов из 23.

## Механизм логического вывода

После каждого ответа выполняются шаги 1–3, поэтому рейтинг видов деятельности (не меньше пяти лучших) обновляется сразу. После последнего вопроса добавляются шаги 4 и 5.

**Шаг 1. Прямой вывод по правилам.** Пока есть правило, условие которого выполнено, а заключение ещё не выведено, система его применяет. Выведенное значение записывается в рабочую базу данных с пометкой, каким правилом оно получено. Если пользователь вернётся и изменит ответ-условие, вывод пересчитается.

**Шаг 2. Профиль предпочтений.** По каждому атрибуту *k* складываются веса выбранных вариантов — это сумма *Pₖ*. По тем же вопросам считаются наименьшая и наибольшая возможные суммы *minₖ* и *maxₖ*. Предпочтение:

pₖ = 2 · (Pₖ − minₖ) / (maxₖ − minₖ) − 1, от −1 (все ответы против) до 1 (все за).

В интерфейсе оно показывается как (Pₖ − minₖ) / (maxₖ − minₖ), от 0 до 100 %. Отсчёт идёт от минимума, а не от нуля: у атрибутов, против которых в анкете нет ни одного ответа (обучение, творчество), иначе предпочтение всегда было бы положительным, и объекты с этими атрибутами выигрывали бы у всех.

**Шаг 3. Ранжирование объектов.** Профиль пользователя p и атрибуты каждого объекта a сравниваются косинусной мерой сходства. Сферы идут с весом w = 2, стиль — с весом 1:

совпадение = Σ wₖ · pₖ · aₖ / (√(Σ wₖ · pₖ²) · √(Σ wₖ · aₖ²)), от −100 % до 100 %.

100 % — профиль деятельности в точности повторяет предпочтения, 0 — не связан с ними, отрицательное значение — свойства деятельности противоречат ответам. Косинус не зависит от того, сколько атрибутов выражено у объекта, поэтому деятельность с тремя свойствами («Участник субботников») не получает преимущества перед деятельностью с десятью («Наставник»). Объекты сортируются по совпадению.

**Шаг 4. Направленность.** Для каждой сферы берётся доля от максимума: Pₖ / 24. Побеждает сфера с наибольшей долей. При равенстве — та, что набрала больше в общем блоке, где человек прямо выбирает между сферами, затем порядок направлений. Если второе место отстаёт меньше чем на 10 п. п., показываются оба направления. Если лучшее набрало меньше 50 %, склонность помечается как слабо выраженная.

**Шаг 5. Объяснение.** Для направленности собираются ответы с наибольшим весом по её сфере, и у каждого есть готовая фраза («Ты знаешь, как сопровождать незрячего…»). Для каждого из трёх лучших видов деятельности показывается, какие атрибуты сильнее всего совпали с профилем и какие ему противоречат.

## Проверка

`npm run check` проверяет базу знаний тремя способами:

- **Структура и требования задания.** Вопросов не меньше 20 при любых срабатываниях правил, параметров не меньше 10, объектов не меньше 20, у каждого объекта значения по всем 13 атрибутам. Веса — в допустимых пределах. Правила ссылаются на существующие вопросы и варианты, заключение идёт после условия. Максимумы сфер равны.
- **Персоны.** Тринадцать выдуманных людей с разными интересами, в том числе те, у кого срабатывают правила. Их ответы подобраны по смыслу вариантов, а не по весам. Для каждого проверяются направленность и то, что хотя бы один ожидаемый вид деятельности попал в тройку лидеров.
- **Случайные ответы.** 20 000 анкет. Каждое направление должно побеждать в 20–30 % случаев. Ни один вид деятельности не должен быть первым чаще чем в 20 % случаев, и каждый должен попадать в пятёрку лидеров хотя бы в 3 % случаев.

Результаты последнего прогона — в [validation.md](validation.md).
