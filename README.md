# Определение волонтерской направленности личности

Домашнее задание по ОИС, МГТУ им. Н.Э. Баумана. Выполнил Волнухин Никита, СГН3-72Б.

Прототип экспертной системы (ДЗ 2-1 «Разработка прототипа экспертной системы»). Система задаёт 23 вопроса о предпочтениях, возможностях и склонностях. После каждого ответа она ранжирует 24 вида волонтёрской деятельности, а в конце называет направленность и объясняет, почему она подходит. Бэкенда нет, вся логика работает в браузере.

**Направления:** дети и подростки · люди с инвалидностью · старшее поколение · экология.

| Требование задания | В системе |
|---|---|
| Вопросов ≥ 20 | 23, задаётся не меньше 20 |
| Параметров от пользователя ≥ 10 | 23 |
| Объектов ранжирования ≥ 20 | 24 вида деятельности |
| Свойств у объекта ≥ 10 | 13 атрибутов |
| После каждого ответа ≥ 5 ранжированных вариантов | панель «Сейчас тебе подходят»: 5 лучших, по кнопке — все 24 |
| В конце — все объекты по рангу | экран результата |
| Автономная база знаний и рабочая БД с просмотром | `content/quiz.json` и localStorage; экраны «База знаний» и «Рабочая БД» |

## Команды

Нужен Node.js 22.18 или новее: скрипты написаны на TypeScript и запускаются без сборки.

```bash
npm install
```

```bash
npm run dev
```

Запускает сайт локально с автообновлением.

```bash
npm run build
```

Проверяет типы и собирает сайт в `dist/`. Посмотреть сборку — `npm run preview`.

```bash
npm run check
```

Проверяет базу знаний, требования задания и картинки. Если что-то не так, завершается с ошибкой.

```bash
npm run docs
```

Пересобирает `docs/knowledge-base.md`, `docs/objects.csv`, `docs/questions.csv`, `docs/validation.md` и `docs/credits.md` после правок в `content/`.

## Деплой на GitHub Pages

Сайт собирает и выкладывает workflow [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) при каждом пуше в `main`: он ставит зависимости, запускает `npm run check` и `npm run build`. Перед первым пушем Pages нужно один раз включить: **Settings → Pages → Build and deployment → Source: GitHub Actions**. Адрес сайта — `https://nvolnukhin.github.io/mgtu-ois/`.

Пути в сборке относительные (`base: './'` в `vite.config.ts`), поэтому сайт работает и из подпапки Pages, и из любой другой.
